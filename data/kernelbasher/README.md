# KernelBasher preview geometry

`torn.json` contains the four Torn-X replacement meshes used by KernelBasher's
preview. It is generated by `torn_meshes()` in
[KernelBasher's build script](https://github.com/yosaito/kernelbasher/blob/b068b018f3147a9bcfaa96ac6390e1b864b3de3a/tools/build_preview.py).
That script applies the recovered KernelBasher patch payload to the upstream
logo block and decodes it with the reference renderer's vertex/index formats.

The original payload is recorded in KernelBasher's `src/original_tables.inc`;
the source logo block is `data/logo/logo.bin` in this repository. This generated
geometry is data, covered by the upstream license's `data/` exclusion. It is
not presented as newly authored MIT-licensed geometry.
